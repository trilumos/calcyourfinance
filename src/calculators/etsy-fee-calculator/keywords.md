# Keyword research — Etsy Fee Calculator

**Primary:** `etsy fee calculator`
**Intent:** Tool. Sellers computing payout/profit before pricing an item.
**Competition:** Medium (trending High) — many dedicated tools (craftybase, runfutureproof, listybox, getonecart, voolist). High volume. Winnable on accuracy + profit angle + country coverage.

## SERP observations (2026-06)
- Crowded with calculators AND "Etsy fees explained 2026" guides (marmalead, gelato, printful).
- Strong secondary intent for **profit margin** ("etsy profit calculator") → we fold profit (item cost input) into the same tool.
- Country processing-fee differences (UK 4% + 20p, EU 4% + €0.30) are under-served → our wedge.

## Our differentiation
- One tool does fees + payout + profit (item cost input).
- 5 countries with correct processing rates.
- Offsite Ads modeled correctly (15%/12%, $100 cap) — many competitors omit or get the cap wrong.
- Transaction fee correctly applied to shipping.
